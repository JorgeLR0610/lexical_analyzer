Ejemplo en java
public class CodigoIntermedio {
public static int ejecutar() {
int a = 5;
int b = 10;
int t1 = a + b;
int t2 = a + b;
int x;
if (t1 > 10) {
x = 1;
} else {
x = 0;
}
int y = x;
int z = 20 + 30;
int w = 100;
return y;
// Código inalcanzable:
// w = 200;
}
public static void main(String[] args) {
System.out.println(ejecutar());
}
}
Observaciones de optimización
Este código contiene varias oportunidades de optimización:
1. Subexpresión común
int t1 = a + b;
int t2 = a + b;
La suma a + b se calcula dos veces. Puede reutilizarse:
int t1 = a + b;
int t2 = t1;
2. Propagación de constantes
int a = 5;
int b = 10;

int t1 = a + b;
Se convierte en:
int t1 = 15;
3. Plegado de constantes
int z = 20 + 30;
Se simplifica a:
int z = 50;
4. Código muerto
int t2 = ...
int z = ...
int w = 100;
Ninguna de estas variables se utiliza antes del return, por lo que pueden
eliminarse.
5. Código inalcanzable
return y;
w = 200;
La asignación w = 200 nunca se ejecutará porque está después del return.
Versión optimizada
public class CodigoOptimizado {
public static int ejecutar() {
int t1 = 15;
int x;
if (t1 > 10) {
x = 1;
} else {
x = 0;
}

return x;
}
public static void main(String[] args) {
System.out.println(ejecutar());
}
}
En esta versión se aplican: eliminación de sub expresiones comunes, propagación de
constantes, plegado de constantes, eliminación de código muerto y eliminación de
código inalcanzable.
