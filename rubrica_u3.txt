Actividad Integradora de la Unidad 3
Optimización de Código Intermedio mediante Grafo de Flujo de Control (GFG)
Objetivo
Aplicar la optimización de código intermedio mediante el análisis de bloques básicos y la
construcción del Grafo de Flujo de Control (GFG), implementando técnicas de
optimización que permitan mejorar la eficiencia del código sin alterar su comportamiento
original.
Instrucciones
A partir del código intermedio proporcionado o desarrollado durante la práctica, realice las
actividades que se describen a continuación:
1. Presentar el código intermedio original
Incluya el código intermedio (IR) antes de aplicar cualquier proceso de optimización.
2. Identificar los bloques básicos
Determine y etiquete correctamente cada bloque básico que forma parte del programa.
3. Construir el Grafo de Flujo de Control (GFG)
Elabore el GFG correspondiente al código analizado, identificando claramente:
•
•
•
•

Nodo de entrada.
Bloques básicos.
Transiciones entre bloques.
Nodos de salida, cuando corresponda.
