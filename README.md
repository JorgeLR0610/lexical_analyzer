# Analizador léxico escrito en Python

Para instalar requerimientos, ejecute el comando:
```
pip install -r requirements.txt
```
Luego, navegue a la carpeta ```app```, abra una terminal y ejecute el comando:
```
fastapi dev main.py
```

Finalmente, abra el navegador y acceda a la dirección [localhost:8000](http:localhost:8000)
